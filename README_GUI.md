# Smart Student Expense Tracker — GUI Version

A desktop interface for the Python Student Expense Tracker, made with Tkinter.

## Features
- Dashboard for monthly budget, total spent, and remaining budget.
- Add expenses with amount, category, date, and description.
- View expenses in a table.
- Save data between sessions in `expenses.json`.
- Budget warning and input validation.

## Requirements
- Python 3 on Windows.
- Tkinter (included with most standard Windows Python installations).
- No third-party packages required.

## Run
Open Command Prompt in this folder and run:

```bash
python expense_tracker_gui.py
```

If needed, try `py expense_tracker_gui.py`.

Keep `expense_tracker_gui.py` and `expenses.json` in the same folder. The JSON file is created automatically after saving a budget or expense.
